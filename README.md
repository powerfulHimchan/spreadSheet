# 시트장부 / FamilyLedger

유사한 형태의 Google 스프레드시트를 연결해 거래 입력·조회·분석에 사용하는 Android 앱입니다. 특정 장부 ID, 실제 거래, 사용자 계정은 소스에 포함하지 않습니다.

## 0.1.0 구현 범위

- Kotlin / Compose / Room, Android 8.0(API 26) 이상
- Google AuthorizationClient를 통한 Sheets 접근 권한 요청. 토큰은 앱 메모리에만 유지
- URL로 장부 연결, 탭 선택, 서로 다른 여러 장부의 연결 설정 저장
- 헤더 위치·연속 표 영역 추천 및 수동 범위 지정. 한 탭 안의 여러 표 후보 선택
- 서식·검증 규칙·최대 100개 표본으로 타입 추론. 수동 타입·역할 지정
- 날짜 / 월별 탭+일자, 숫자 로케일 지정, 선택 목록·체크박스·통화·퍼센트 지원
- 날짜·금액·카테고리·작성자·결제수단·수입/지출 등 역할 매핑
- 수식 열 읽기 전용. 원본 표 주변의 데이터와 서식 보존
- 사용자 확인 후 숨겨진 거래 ID/삭제 상태 열 추가. 지정 영역의 빈 행 추가, ID 기반 수정, 논리 삭제
- 저장 전 재조회와 원본 셀 비교, 중복 ID와 변경 감지 시 저장 차단
- Room에 마지막 스냅샷 보관. 오프라인 조회 지원, 오프라인 쓰기 큐 없음
- 월 요약, 거래 검색·카테고리·작성자·구분 필터, 거래 복사, 카테고리별·월별 그래프
- 구조가 다른 가상 샘플 3개. 샘플 수정은 실제 시트에 전송되지 않음
- 화면 캡처 차단, Android 백업 비활성화, HTTPS 전용, 거래/토큰 로그 출력 없음

## 실행

Android Studio로 루트 폴더를 열거나 JDK 17과 Android SDK 35를 설치하고 실행합니다.

```sh
./gradlew :core:test :app:lintDebug :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`

처음에는 **먼저 살펴보기**에서 Google 계정 없이 동작을 확인합니다. 실제 연결에는 [Google 인증 설정](docs/GOOGLE_SETUP.md)이 필요합니다.

## 모듈

| 모듈 | 역할 |
|---|---|
| core | 순수 Kotlin: 표 인식, 타입·역할, 날짜·정밀 금액 처리, 분석, 안전한 변경 계획 |
| app | Compose 화면, Google 권한, Sheets REST 통신, Room 캐시·장부별 매핑 |

## 최초 연결 흐름

1. 스프레드시트 URL 입력 → Google 계정으로 시트 접근 승인
2. 사용할 탭 선택
3. 헤더 행·열 범위·입력 마지막 행 확인. 안내/소계/다른 표는 제외
4. 타입과 역할 확인. 월별 일자 방식은 연도·월도 지정
5. 조회와 분석 시작
6. 추가·수정 사용 시 **안전한 편집 설정**을 선택. 원본에 숨겨진 ID·삭제 열 2개를 추가하는 내용을 확인

소스 데이터에 기존 ID가 있으면 ID 역할과 삭제 여부 역할을 직접 지정할 수도 있습니다. 앱은 거래 행 전체를 삭제하거나 주변 표를 이동하지 않습니다.

## 알려진 제한과 검증 범위

- 현재 매핑은 기기별 로컬 저장. 가족 공통 설정 탭과 자동 매핑 공유는 후속 범위
- 같은 헤더의 월별 탭 일괄 연결, 연결된 탭 사이 월 이동, 같은 장부의 연결된 표 통합 분석 지원. 통합 분석은 각 표의 마지막 동기화 스냅샷을 사용하며 전체 새로고침 가능. 겹치는 연결의 동일 거래 좌표는 중복 집계하지 않음
- 자동 추천은 일반적인 헤더의 연속된 표에 최적화. 병합·다단 헤더, 교차표, 피벗을 임의로 평탄화하지 않으며 수동 범위 확인 필요
- 초기 조회는 탭당 최대 10,000행·200열. 초과 시 불완전 상태를 표시하고 쓰기 차단
- 금액 계산은 BigDecimal. Google Sheets 숫자의 유효 정밀도를 고려하여 숫자 저장은 최대 유효 15자리·안전한 정수 범위로 제한
- 수식/배열 수식이 포함된 열 전체는 읽기 전용. 해석하지 못한 범위 검증·커스텀 체크박스도 읽기 전용
- 새 거래는 확인한 입력 영역 안의 빈 행만 사용. 영역이 가득 차면 사용자에게 확장을 안내하며, 기존 유한 범위 합계 수식을 자동 확장하지 않음
- 삭제는 원본 값을 유지하고 삭제 플래그만 변경. **앱의 합계에서는 제외되지만 기존 시트의 SUM 수식은 삭제 플래그를 자동 반영하지 않음.** 시트 합계에도 논리 삭제를 반영하려면 소유자가 SUMIFS 등으로 별도 설정해야 함. 앱에서 수식을 자동 수정하지 않음
- Sheets API에는 앱이 사용할 수 있는 행 단위 비교 후 쓰기의 원자적 CAS가 없음. 저장 전 재검사로 일반적인 충돌을 차단하지만, 여러 기기에서 정확히 동시에 저장하는 경쟁을 완전히 제거하지 못함. 강한 동시성 보장이 필요하면 서버/Apps Script 직렬화가 후속 설계에 필요
- 네트워크 오류가 발생한 쓰기 요청은 자동 재전송하지 않음. 새로고침하여 반영 여부를 확인한 뒤 다시 작업
- 로컬 DB는 앱 전용 저장소에 저장하나 SQLCipher 암호화·앱 생체 잠금은 아직 미구현
- 앱은 Google 인증과 API 경로를 구현했지만, 소유자의 Cloud 설정 전에는 실제 계정으로 연결·쓰기의 최종 검증을 할 수 없음
- 테스트용 debug APK. Play 배포·실사용 release 서명은 별도로 설정 필요. 서명 SHA-1 변경 시 OAuth Android 클라이언트도 다시 등록

현재 상태와 실행 검증 결과는 `docs/VERIFICATION.md`에 기록합니다.

## 자동 검증

`main` 반영과 PR에서 GitHub Actions가 핵심 테스트·Android lint·debug APK 빌드를 실행합니다. 성공한 실행의 `FamilyLedger-debug` 아티팩트에서 APK를 받을 수 있습니다. CI의 debug 서명은 최초 preview APK와 다를 수 있으므로 실제 Google 인증에는 설치할 APK의 SHA-1을 등록해야 합니다.
